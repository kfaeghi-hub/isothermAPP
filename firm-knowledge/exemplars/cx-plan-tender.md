# Exemplar — Cx Plan, tender tier

**Skeletons only (ruling D7).** The tender tier is the standard tier **plus five
chapters** and a richer opening — not a different document. Derived from the
Seneca structure.

## Differences from the standard tier

| § | Section | Tag | Note |
|---|---|---|---|
| 1 | **Introduction** (1.1 Project Description · 1.2 Purpose · 1.3 · 1.4) | N + B | Replaces the single Executive Summary. 1.1 carries a fact block: project name, location, building type, gross floor area — all **D**, all from project data. Never emit a placeholder for a missing one; omit the line. |
| 4 | Commissioning Process and Roles & Responsibilities | B + N | Merged chapter. Cites ASHRAE Guideline 0 where the project invokes it. |
| **5** | **Commissioning Execution Procedures** | B + D | Tender-only. Procedure library, full set. |
| **6** | **Integrated Life Safety Systems Testing** | B + N | Tender-only. `life_safety` procedure bullets. |
| **7** | **Testing, Adjusting and Balancing of Mechanical Systems** | B + N | Tender-only. `tab` procedure bullets. |
| **8** | **Commissioning Schedule** | N + D | Tender-only. Phases from project data; narrative on sequencing. |
| 9 | Documentation and Reporting | B + D | Extended: reporting cadence and dispute resolution. |
| **10** | **Quality Assurance** | B | Tender-only. |
| 11 | Appendix (A–L) | D | Twelve appendices; six are living records in this app. |

## The living-document clause — B

The tender tier states its own revision model, which the composer's lifecycle
implements:

> The Cx Plan is a living document. It will be revised and reissued at key
> milestones, including pre-construction, mid-construction and prior to
> substantial performance.
