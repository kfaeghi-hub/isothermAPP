# Feature contract — fpt

**STUB.** Not built. Recorded so the contract layer is visibly per-feature from
the start, and so the next feature is written as a contract rather than as a
prompt embedded in an endpoint.

When built, this file states: what the model drafts, what it never sees, the hard
constraints, the return shape, whether a verification call applies, and the
budget. It must not restate identity, style or terminology — those arrive from
the shared corpus. **A contract that duplicates corpus content is the drift this
architecture exists to prevent.**
